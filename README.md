# CarCast Hub — personal TDS integration

نسخة دمج 0.1 مبنية فوق المشروع المرفق TDS، وليست إعادة بناء له من الصفر.

**الحالة:** تمت إضافة الكود ومراجعة بنية المشروع. لم يُنفّذ بناء Xcode أو اختبار الأجهزة في بيئة التسليم؛ لا يوجد IPA جديد مبني داخل هذا الملف. الـworkflow ينشئه عند نجاح البناء.

## التشغيل المختصر من GitHub

1. أنشئ مستودع GitHub **Private** لاستخدامك الشخصي.
2. ارفع محتويات هذا المجلد إلى جذر المستودع، بما فيها `.github` و`TDS Video.xcodeproj`. لا ترفع ملف ZIP وحده.
3. افتح **Actions → Build CarCast Hub unsigned IPA → Run workflow**.
4. بعد النجاح، نزّل **CarCastHub-unsigned** من **Artifacts**؛ ستجد ملف IPA داخله.
5. إذا فشل: نزّل **CarCastHub-build-logs** وأرسل `build.log`، أو `packages.log` إن فشل تنزيل التبعيات، أو `parser-tests.log` إن فشلت اختبارات الاستيراد.

في Finder اضغط **Command + Shift + .** لإظهار مجلد `.github` عند الرفع. تأكد بعد الرفع أن ملف `.github/workflows/unsigned-ipa.yml` موجود في GitHub.

GitHub يبني على macOS 15 باستخدام Xcode 26.3. لا تحاول فتح هذا المشروع الحديث بـXcode 12.4 على Catalina. استخدام GitHub لا يتطلب ترقية الماك. البناء على مستودع خاص يستهلك رصيد Actions المتاح لحسابك؛ لا نفعّل أي اشتراك مدفوع.

**Unsigned لا يعني قابلًا للتثبيت مباشرة.** التوقيع وصلاحيات الامتدادات وCarPlay مسألة منفصلة. لا يوجد وعد بأن توقيعًا شخصيًا عاديًا سيسمح بكل صلاحيات TDS على الآيفون غير المكسور الحماية.

## الموجود في الكود

- عدة مزودين؛ M3U/M3U8 من رابط أو ملف، وXtream Codes.
- Live TV / Movies / Series؛ فئات وبحث وصفحات من 100 عنصر.
- مسلسلات Xtream بمواسم وحلقات، وM3U بأسماء واضحة مثل `Example S01E02`.
- مفضلة، سجل، مؤخرًا، واستكمال أفلام وحلقات.
- مشغل AVPlayer، تقديم/ترجيع 10 ثوان، ملء الشاشة، السابق/التالي ضمن القائمة المحملة، AirPlay وPiP وفق دعم الجهاز والمحتوى، وخيارات الصوت والترجمة الأصلية حيث يوفرها البث.
- XMLTV غير مضغوط حتى 64 MB، مع بيانات البرامج في صفحة القناة. تحديثه يدوي من Providers.
- متصفح WKWebView مستقل مع عناوين ومفضلة وسجل؛ متصفح TDS الأصلي باقٍ في مساحة TDS.
- Files / Photos / رابط مباشر، مع إبقاء Share Extension الأصلي.
- Car Mode يفتح أدوات TDS الأصلية للمرايا والمتصفح والخادم. زر إرسال البث إلى مسار CarPlay الأصلي عند وجود جلسة.
- SQLite للمكتبة، Keychain لبيانات المزود، واستيراد خارج واجهة المستخدم.

## الحدود التي يجب معرفتها قبل الاختبار

- الحد الأدنى الحالي **iOS 17** كما في التطبيق الأصلي: iPhone 7 على iOS 15 ليس ضمن نسخة الدمج هذه.
- لا تُعدّ الإضافة محققة وظيفيًا قبل نجاح البناء وتجربة مزود حقيقي. لم نستلم بيانات مزود للاختبار.
- لا ضمان لتشغيل Netflix/TOD/STARZPLAY؛ لم نكسر DRM أو ننسخ كود التطبيقات المرجعية.
- CarPlay في TDS يستخدم تقنيات خاصة/غير مدعومة. السورس الأصلي نفسه يعرض تنبيه عدم دعم iOS 26 في واجهته القديمة. لم يُزل التنبيه ولم نثبت التوافق مع 26.6.2.
- ReplayKit في السورس يتجاهل عينات الصوت، وخادم HTTP يرسل صورًا بلا صوت. مشكلة صوت السيارة تحتاج تحديد المسار الفعلي وتجربة على الجهاز؛ لم تُصلح بالتخمين.
- HLS/MP4 يعملان فقط مع codecs يدعمها AVPlayer. TS الخام/MKV وبعض المزودين قد يحتاجون libVLC؛ لم نُضف libVLC في هذه النسخة.
- جودة HLS تكيفية تلقائيًا؛ لا توجد قائمة يدوية شاملة لجودات المزود. EPG gzip غير مدعوم بعد. ملفات M3U المحلية لا تحتوي خيار XMLTV في هذه النسخة؛ استخدم مزود رابط لإضافة دليل.
- لا مزامنة لتقدم المشاهدة من مشغل TDS القديم إلى المكتبة الجديدة بعد إرسال الفيديو للسيارة.
- الاعتماد الأصلي AirPlayReceiver يُنزّل من مستودع مطوره. تعذر التحقق من إتاحته هنا؛ إذا فشل Resolve فلا نحذفه، بل نصلح الوصول للتبعية أو نوفر نسختها الأصلية.
